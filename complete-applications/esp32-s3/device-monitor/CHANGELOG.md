# 变更记录

## 1.8.0 - 2026-07-31

比较基线：`v1.7.6`（`04dfca5345f3b3ae6b0afa94e8a4d1d49986d214`）。

### 新增与改进

- 小钛新增联系人状态查询，以及设备联系人、微信联系人呼叫动作。
- 设备联系人支持音频和视频呼叫；微信联系人当前支持语音呼叫。
- 设备呼叫补齐 `call_type` 校验与传播，共享 RTC 命令按设备呼叫和微信会话正确分流。
- 微信联系人兼容 `data.contacts`、`data.list` 及常见字段别名。
- 微信联系人支持异步更新备注，使用 NVS schema v2 保存缓存，并在更新后刷新服务端权威列表。
- 联系人界面新增 9 个预设备注：妈妈、爸爸、爷爷、奶奶、外公、外婆、哥哥、姐姐、朋友。
- AI 品牌名称统一为“小钛”和“小钛设置”。
- 新增 43 组、每组 10/12/16 三种尺寸，共 129 张界面文本资源。

### 兼容性

- TiRTC SDK 保持 `2.2.0`，本版本未替换 SDK 静态库。
- ESP-IDF 保持 `5.5.4`，Flash、分区表和硬件目标保持不变。
