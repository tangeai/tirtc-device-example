# AI 对讲字库词表来源

这里是 AI 对讲动态中文的字库源头文件。只有 ASR/TTS 字幕、AI 回复、AI 对讲状态这类运行时变化的中文，才应该补充到这里；设置、OTA、网络测试、呼叫等固定界面中文必须从 Figma 导出 PNG，不再通过字库显示。

## 文件说明

- `00_punctuation.txt`: 中文标点、ASCII 标点、数字和英文字母。
- `05_fallback_terms.txt`: 兜底 C 字库词表，只覆盖字库分区缺失时的恢复提示。
- `15_ai_chat_ui_terms.txt`: AI 对讲页状态、字幕占位和设置项；用于兜底字库，避免外置字库未烧录时显示为点。
- `10_core_ui_terms.txt`: 历史保留的核心词表，新字库生成流程不再把普通 UI 固定中文作为优先来源。
- `20_ai_chat_domain_terms.txt`: AI 玩具、AI 对讲、RTC、网络、OTA 领域词。
- `90_common_compact.txt`: 常用汉字补充池。
- `95_common_3500.txt`: 3500 常用汉字扩展池，用于在分区空间允许时继续扩大覆盖面。
- `96_common_7000.txt`: 7000 常用字扩展池，用于覆盖更多自然语言回复。
- `97_standard_8105.txt`: 《通用规范汉字表》2013 全部 8105 字的纯字符版本。

生成脚本只扫描 AI 对讲相关服务代码，再和 AI 词表、常用字池合并。固定 UI 中文应该补 Figma PNG 资产，不应该补进字库。
