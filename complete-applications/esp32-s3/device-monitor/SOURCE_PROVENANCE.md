## 1.9.0 变更范围

源工程相对 `v1.8.0` 的正式交接共涉及 `87` 个文件、`12,926` 行新增和 `3,083` 行删除。
主要变化是：

- TiRTC SDK 从 `2.2.0` 升级到同一官方包内的 `2.3.0 mini` 头文件、静态库、统计接口和
  TGTRP 接口。
- 音频链路增加 AEC、抖动缓冲、缺帧补偿、校验失败/缺失/重复/乱序统计和诊断入口。
- TiRTC 连接、任务栈、PSRAM 与 internal RAM 分配策略按新 SDK 和 S3 资源边界收口。
- Device Call、小钛、Web IPC 和微信 VoIP 共用的 RTC 生命周期与断开流程统一由应用层仲裁。
- Wi-Fi、弱网、Socket、RTC、媒体、AEC 和呼叫状态增加串口 AT 诊断 CLI；公开默认配置开启，
  不需要诊断的产品构建可以关闭。
- 产品能力固定为 RTC 双向音频；摄像头保留给二维码扫描，不再作为 RTC 视频源。
- 继续使用 16 MB Flash、8 MB PSRAM、双 `0x770000` OTA app 分区和 1 kHz FreeRTOS tick。

## 公开筛选

统一仓保留应用源码、构建所需组件、`sdkconfig.defaults`、分区表、公开开发者文档和必要辅助
脚本。以下内容不会进入公开源码快照：

- 来源仓 Git 元数据、本地 `AGENTS.md`、本地 Skill、IDE 配置和开发机完整 `sdkconfig`。
- `build/`、`build-current/`、`managed_components/`、日志、NVS 转储、ELF、MAP 和固件镜像。
- 真实 Wi-Fi、设备身份、密钥、Token、串口记录和个人绝对路径。
- 内部交接、一次性审阅材料、旧版本构建目录和与本版本无关的调试资料。

公开筛选不会重写 TiRTC SDK 静态库。库内 BuildInfo 和 SHA-256 保持供应包原样；SDK 头文件、
库、组件构建契约和版本说明作为一个整体核对。

统一公开代码快照。这些证据仍不替代目标板烧录、联网和业务运行验证。
